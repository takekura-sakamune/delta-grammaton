## PDFの公開と閲覧

`reader.html` がPDFリーダーです。各作品の「PDFを読む」から開くと、その作品を自動表示します。リーダーを直接開いた場合は一覧の先頭作品を自動表示します。

ローカル確認は「サイトを確認.cmd」を実行し、表示された `http://127.0.0.1:8766` をブラウザーで開いてください（Pythonが必要です）。HTMLのダブルクリックではPDFを読み込めません。

1. 公開するPDFを `pdf/` フォルダーに置きます。
2. `pdf/catalog.json` に次の形式で追加します（複数作品はカンマで区切ります）。ファイル名は実際のPDFに合わせてください。

```json
[
  { "title": "作品名", "file": "pdf/作品名.pdf" }
]
```

3. サイトのファイルとPDFをまとめて通常のホスティング先へ配置します。

単ページ／右綴じの見開きを選択できます。「先頭1ページを単独表示」をオンにすると1／2–3／4–5、オフにすると1–2／3–4の組み合わせになります。見開きでは小さいページ番号が右側です。末尾が1ページ余る場合は単独表示します。

←または↓で次、→または↑で前のページ（見開き時は次・前の見開き）へ移動します。バーをドラッグすると連続して移動できます。選択欄やバーなどにフォーカスがある間は、その入力部品の標準キー操作を優先します。

「手元のPDFを開く」はブラウザー内だけで読み込み、サーバーへ保存しません。サイトに永続的に公開する場合は上記の配置手順を使ってください。

PDF.js 4.10.38は `vendor/pdfjs/` に同梱しています。このフォルダーもまとめて公開してください。外部CDNへの接続は不要です。`file://` で直接開かず、HTTP(S)で配信してください。PDFページは画像として描画するため、本文の文字選択や検索には対応していません。

## 閲覧画面の操作

PCの初期表示は見開き、幅767px以下のタッチ端末では単ページです。先頭1ページの単独表示は初期状態でオフです。

画面下端から160px以内にカーソルを近づけると、PDFに重なるページ移動バーと倍率操作が現れます。左右端から90px以内では、左に「次へ」、右に「前へ」が現れます。キーボードでも各操作へフォーカスできます。タッチ端末はPDFをタップして操作を表示し、4秒後に自動で隠れます。

倍率は50〜300％で指定でき、＋／−は10％ずつ変更します。「画面に合わせる」は100％へ戻します。100％は閲覧領域に収まるサイズが基準です。拡大時はPDF領域を縦横にスクロールできます。

上部の作品・設定もPDFに重ねて表示し、上端へカーソルを近づけると現れます。PDF領域内では下スクロールで次、上スクロールで前へ移動します。見開き時は見開き単位です。トラックパッドの慣性による連続移動を防ぐため、1回のジェスチャーで1回だけ移動します。拡大中のPDFをスクロールするにはShiftを押しながら操作してください。
